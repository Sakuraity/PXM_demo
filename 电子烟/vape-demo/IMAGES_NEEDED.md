# NEXVAP 电子烟 Demo 图片需求清单

## 视觉风格指南

网站整体采用 **黑色高级感/现代工业风**，但不同场景使用不同的视觉处理方式：

### 主色调
- **深色基调**: 纯黑 (#000000)、深灰 (#0a0a0a, #111111)
- **强调色**: 金属金 (#d4af37)、科技蓝 (#38bdf8)、能量橙 (#f59e0b)

### 图片风格多样化建议

| 图片类型 | 推荐风格 | 背景/环境 |
|---------|---------|----------|
| **产品主图 (Hero)** | 高端产品摄影 | 深色渐变背景 + 轮廓光 |
| **产品展示图 (Gallery)** | 干净商业摄影 | 纯白或浅灰背景 |
| **产品场景图 (Lifestyle)** | 生活化场景 | 真实环境（咖啡馆、办公室、户外） |
| **系列横幅 (Series)** | 情绪化大片 | 抽象渐变或环境氛围 |
| **分类图片 (Categories)** | 产品组合 | 统一色调的产品陈列 |
| **用户头像 (Avatars)** | 专业商务 | 简洁中性背景 |

### 技术规格

- **格式**: JPG (照片) / PNG (需要透明背景时)
- **色彩空间**: sRGB
- **质量**: 高品质 85-90%
- **分辨率**: 72ppi (网页)
