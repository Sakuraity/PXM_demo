# 美妆包材 Demo 业务结构设计

> **Demo 品牌**：LuxePack — 高端定制美妆包材制造商  
> **业务模式**：B2B，面向全球美妆品牌方提供定制化包装解决方案

---

## 一、产品体系

### 1.1 三级分类结构

```
LuxePack 产品体系
│
├── 护肤包装（Skincare Packaging）
│   ├── 面霜罐（Face Cream Jars）
│   │   ├── 玻璃面霜罐
│   │   ├── 亚克力面霜罐
│   │   └── PP 可补充面霜罐
│   ├── 精华瓶（Serum Bottles）
│   │   ├── 滴管精华瓶
│   │   └── 泵头精华瓶
│   ├── 乳液瓶（Lotion Bottles）
│   │   ├── 泵头乳液瓶
│   │   └── 无泵乳液瓶
│   ├── 喷雾瓶（Spray Bottles）
│   ├── 真空瓶（Airless Bottles）
│   └── 套装系列（Sets）
│
├── 彩妆包装（Makeup Packaging）
│   ├── 口红管（Lipstick Tubes）
│   ├── 唇釉管（Lip Gloss Tubes）
│   ├── 粉底液瓶（Foundation Bottles）
│   ├── 气垫盒（Cushion Compacts）
│   └── 眼线笔管（Eyeliner Tubes）
│
└── 家清包装（Home & Personal Care）
    ├── 洗发水瓶（Shampoo Bottles）
    ├── 沐浴露瓶（Body Wash Bottles）
    ├── 泡沫泵瓶（Foam Pump Bottles）
    └── 手部护理瓶（Hand Care Bottles）
```

### 1.2 按材质分类（横向维度）

| 材质 | 特点 | 适用产品 | 价位 |
|-----|------|---------|------|
| **玻璃** | 高端感、防氧化、可回收 | 精华瓶、面霜罐、香水瓶 | 高 |
| **亚克力（PMMA）** | 类玻璃质感、轻便、耐摔 | 面霜罐、乳液瓶 | 中高 |
| **PP（聚丙烯）** | 环保可回收、耐化学性好 | 可补充套装、软管 | 中 |
| **PET** | 透明度高、轻便 | 乳液瓶、洗发水瓶 | 中低 |
| **HDPE** | 硬度高、耐挤压 | 洗护发瓶、家清瓶 | 低 |
| **铝** | 轻量化、高端感 | 旅行装、香水瓶 | 中高 |

### 1.3 按包装类型分类（横向维度）

| 类型 | 说明 | 代表产品 |
|-----|------|---------|
| **瓶（Bottles）** | 细口、有泵头或滴管 | 精华瓶、乳液瓶 |
| **罐（Jars）** | 宽口、旋转开盖 | 面霜罐、眼霜罐 |
| **管（Tubes）** | 软管，挤压出料 | 眼霜管、防晒管 |
| **泵头（Pumps）** | 按压式出料装置 | 泡沫泵、乳液泵 |
| **安瓿（Ampoules）** | 单次使用密封小管 | 精华安瓿、美白安瓿 |

## 二、核心产品数据结构

### 2.1 产品核心属性

每个产品由以下维度描述（对应 PXM PIM 模块的属性配置）：

**基础信息**
- 产品名称（中/英文）
- 产品系列
- 所属分类（应用 + 材质 + 类型 三个维度）
- 产品 slug（URL 标识）

**技术规格**
- 容量（ml）：如 15ml / 30ml / 50ml / 100ml
- 材质：主材质 + 配件材质
- 外径/高度（mm）
- 净重（g）
- 开口尺寸（mm）

**定制选项**
- 可选颜色（标准色 + 潘通定制）
- 表面处理：光面 / 哑面 / 磨砂 / 电镀
- 印刷工艺：丝印 / 烫金 / 压纹 / UV 印刷
- 是否支持 Logo 定制
- 是否支持换色

**商务信息**
- MOQ（最小起订量）：500 / 1000 / 3000 / 5000
- 阶梯价格（3-4档）
- 交期（天）：标准款 / 定制款
- 样品费用

**媒体资产**（对应 PXM DAM 模块）
- 主图（1张）
- 产品图库（4-8张）
- 3D 模型链接（部分产品）
- 技术图纸（可选）

## 三、B2B 业务流程

### 3.1 客户旅程

```
发现阶段          评估阶段          决策阶段          执行阶段
─────────────    ─────────────    ─────────────    ─────────────
浏览分类导航  →  产品筛选比较  →  询价/样品申请  →  下单/生产跟踪
     ↓                ↓                ↓                ↓
查看热门产品       产品详情查看      3D效果预览        支付/物流
     ↓                ↓                ↓                ↓
关注新品/案例      规格参数确认      方案定制          收货验收
```

### 3.2 询价流程

```
客户填写询价表单
    ↓
系统自动确认邮件（含询价编号）
    ↓
销售 24h 内响应（Demo 中展示流程）
    ↓
发送初步报价单（PDF）
    ↓
样品确认（可选）
    ↓
正式下单
```

### 3.3 定制服务流程

```
选择基础产品
    ↓
进入定制配置界面（3D 预览）
    ├── 选择颜色（色卡 / 潘通号输入）
    ├── 选择表面处理（光面/哑面/电镀）
    ├── 上传 Logo / 设计稿
    └── 选择印刷工艺
    ↓
保存定制方案（心愿单）
    ↓
一键提交询价（含定制需求）
```

## 四、页面内容规划

### 4.1 首页内容结构

| 模块 | 内容 | PXM 关联 |
|-----|------|---------|
| Hero Banner | 品牌定位语 + 视觉大图 + CTA | DAM 图片管理 |

| 核心优势 | 4 项 USP + 图标 | 静态内容 |
| 数字展示 | 500+ 产品 / 200+ 客户 / 15 年经验 | 静态数据 |
| 客户案例 | 合作品牌 Logo 墙 | CMS 案例管理 |
| 联系 CTA | 询价入口 | 表单提交 |

### 4.2 产品列表页筛选项

```typescript
// 筛选维度（对应 PIM 属性）
interface ProductFilters {
  application: 'skincare' | 'makeup' | 'homecare'  // 应用场景
  material: 'glass' | 'acrylic' | 'pp' | 'pet' | 'hdpe' | 'aluminum'  // 材质
  type: 'bottle' | 'jar' | 'tube' | 'pump' | 'ampoule'  // 包装类型
  capacity: '0-30' | '30-100' | '100-300' | '300+'  // 容量范围（ml）
  isCustomizable: boolean  // 是否可定制
  isNew: boolean  // 是否新品
}
```

### 4.3 产品详情页内容模块

```
产品详情页

    └── 4-6 个同类/配套产品
```

## 五、多语言规划

Demo 支持中文 / 英文双语，体现 PXM 的多语言管理能力：

| 内容类型 | 多语言字段 |
|---------|---------|
| 产品名称 | `name.zh` / `name.en` |
| 产品描述 | `description.zh` / `description.en` |
| 规格标签 | `specs[].label.zh` / `specs[].label.en` |
| 分类名称 | `category.name.zh` / `category.name.en` |
| UI 文案 | `locales/zh.json` / `locales/en.json` |

## 六、Demo 演示脚本

### 演示路径 A：产品管理能力
1. 进入产品列表页 → 展示多维筛选（PIM 属性管理）
2. 切换语言 → 展示多语言发布
3. 进入产品详情 → 展示结构化参数（PIM 数据质量）
4. 查看图片库 → 展示 DAM 数字资产管理

### 演示路径 B：定制配置能力
1. 进入产品详情 → 点击"3D 配置"
2. 选择材质/颜色 → 实时 3D 预览（Studio）
3. 上传 Logo → 效果预览
4. 保存方案 → 转化为询价

### 演示路径 C：B2B 业务流程
1. 首页 → 品牌定位展示
2. 产品浏览 → 选型过程
3. 加入询价列表 → 多产品对比
4. 提交询价 → 流程结束
