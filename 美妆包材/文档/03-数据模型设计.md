# 美妆包材 Demo 数据模型设计

> 基于 PXM PIM 的数据管理理念，设计 Demo 的核心数据结构  
> 所有 JSON 数据文件直接模拟 PXM 向前端输出的数据格式

---

## 一、核心数据文件

| 文件 | 说明 | 记录数 |
|-----|------|-------|
| `categories.json` | 产品分类体系（三维：应用/材质/类型） | ~20 条 |
| `products.json` | 产品主数据 | ~40 条 |
| `materials.json` | 材质库 | ~10 条 |
| `site-config.json` | 站点配置（导航、首页内容） | 1 条 |

## 二、分类数据模型（categories.json）

分类体系支持三个独立维度，每个维度是独立的分类树：

```typescript
interface Category {
  id: string           // 唯一标识，如 "skincare"
  slug: string         // URL 路径段，如 "skincare"
  dimension: "application" | "material" | "type"  // 所属维度
  name: {
    zh: string
    en: string
  }
  description: {
    zh: string
    en: string
  }
  image: string        // 分类封面图路径
  icon?: string        // 可选图标名称（Lucide）
  parent?: string      // 父分类 ID（支持二级分类）
  sortOrder: number    // 排序
  productCount: number // 该分类下产品数（冗余字段，便于展示）
}
```

**分类数据示例**：
```json
[
  {
    "id": "skincare",
    "slug": "skincare",
    "dimension": "application",
    "name": { "zh": "护肤包装", "en": "Skincare Packaging" },
    "description": {
      "zh": "专为护肤品牌打造的高品质包装解决方案",
      "en": "Premium packaging solutions crafted for skincare brands"
    },
    "image": "/images/categories/skincare.jpg",
    "sortOrder": 1,
    "productCount": 18
  },
  {
    "id": "face-cream-jars",
    "slug": "face-cream-jars",
    "dimension": "application",
    "name": { "zh": "面霜罐", "en": "Face Cream Jars" },
    "parent": "skincare",
    "sortOrder": 1,
    "productCount": 8
  }
]
```

## 三、产品数据模型（products.json）

```typescript
interface Product {
  // ── 基础信息 ──────────────────────────────────
  id: string                    // 唯一 ID
  slug: string                  // URL slug
  modelNumber: string           // 产品型号，如 "LPK-GJ-001"
  status: "published" | "draft" | "archived"
  isNew: boolean                // 是否新品（首页展示）
  isFeatured: boolean           // 是否精选（热门推荐）
  isCustomizable: boolean       // 是否支持定制

  name: {
    zh: string
    en: string
  }
  tagline: {                    // 一句话卖点
    zh: string
    en: string
  }
  description: {
    zh: string
    en: string
  }

  // ── 分类关联（三维分类） ────────────────────────
  categories: {
    application: string         // 应用分类 ID，如 "face-cream-jars"
    material: string            // 材质分类 ID，如 "glass"
    type: string                // 类型分类 ID，如 "jar"
  }
  tags: string[]                // 标签，如 ["refillable", "eco-friendly", "luxury"]

  // ── 技术规格 ───────────────────────────────────
  specs: {
    capacity: number            // 容量（ml）
    capacityOptions?: number[]  // 可选容量规格，如 [15, 30, 50]
    height: number              // 高度（mm）
    diameter: number            // 外径（mm）
    neckSize?: number           // 开口尺寸（mm）
    weight: number              // 净重（g）
    material: string            // 主材质，如 "Glass"
    innerMaterial?: string      // 内胆材质（双层结构）
    lidMaterial?: string        // 盖子材质
    finish: string[]            // 表面处理，如 ["Matte", "Glossy", "Frosted"]
    color: string[]             // 可选颜色，如 ["Clear", "Amber", "Black", "White"]
    pantoneCustom: boolean      // 是否支持潘通定制色
    printing: string[]          // 支持的印刷工艺
    certification?: string[]    // 认证，如 ["FDA", "REACH", "ISO9001"]
  }

  // ── 商务信息 ───────────────────────────────────
  moq: number                   // 最小起订量
  pricing: {
    currency: "USD"
    tiers: Array<{
      minQty: number
      maxQty?: number
      unitPrice: number
    }>
  }
  leadTime: {
    standard: number            // 标准款交期（天）
    custom: number              // 定制款交期（天）
  }
  sampleFee: number             // 样品费（USD）
  sampleFeeRefundable: boolean  // 样品费是否下单后退还

  // ── 媒体资产（DAM） ────────────────────────────
  images: Array<{
    url: string
    alt: {
      zh: string
      en: string
    }
    type: "hero" | "gallery" | "detail" | "lifestyle"
    sortOrder: number
  }>
  has3DModel: boolean           // 是否有 3D 模型
  model3DUrl?: string           // 3D 配置器链接

  // ── 关联数据 ───────────────────────────────────
  relatedProducts: string[]     // 相关产品 ID 列表
  packagingSuggestions?: {      // 搭配建议
    zh: string
    en: string
  }

  // ── 系统字段 ───────────────────────────────────
  createdAt: string
  updatedAt: string
}
```

## 四、材质数据模型（materials.json）

```typescript
interface Material {
  id: string                    // 如 "glass"
  slug: string
  name: {
    zh: string
    en: string
  }
  description: {
    zh: string
    en: string
  }
  properties: {                 // 材质特性（用于筛选和展示）
    transparent: boolean        // 透明度
    recyclable: boolean         // 可回收
    lightweight: boolean        // 轻量化
    premiumFeel: boolean        // 高端质感
    chemicalResistant: boolean  // 耐化学品
    heatResistant: boolean      // 耐热
  }
  pros: {                       // 优势（多语言）
    zh: string[]
    en: string[]
  }
  cons: {
    zh: string[]
    en: string[]
  }
  typicalUse: {                 // 典型用途
    zh: string
    en: string
  }
  image: string
  sortOrder: number
}
```

## 五、站点配置数据（site-config.json）

```typescript
interface SiteConfig {
  brand: {
    name: string                // "LuxePack"
    tagline: {
      zh: string
      en: string
    }
    logo: string
    contact: {
      email: string
      phone: string
      address: { zh: string; en: string }
    }
  }

  stats: Array<{               // 首页数字展示
    value: string              // 如 "500+"
    label: { zh: string; en: string }
  }>

  advantages: Array<{          // 核心优势
    icon: string               // Lucide 图标名
    title: { zh: string; en: string }
    description: { zh: string; en: string }
  }>

  certifications: string[]     // 认证图标

  navigation: {
    main: Array<{
      label: { zh: string; en: string }
      href: string
      children?: Array<{
        label: { zh: string; en: string }
        href: string
      }>
    }>
  }
}
```

## 七、产品 slug 命名规范

```
{品牌}-{材质缩写}-{类型缩写}-{序号}

示例：
lpk-glass-jar-001       → 玻璃面霜罐 001
lpk-acrylic-jar-001     → 亚克力面霜罐 001
lpk-glass-bottle-001    → 玻璃精华瓶 001
lpk-pp-tube-001         → PP 软管 001
```
