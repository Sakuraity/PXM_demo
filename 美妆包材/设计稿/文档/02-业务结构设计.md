## 一、产品体系

### 1.1 三维分类结构（扁平化）

产品分类取消二级子分类，改为三个独立维度，每个产品同时拥有三个维度的标签，在列表页通过筛选器联动展示。

| `skincare` | 护肤包装 | Skincare Packaging | 8 |
| `makeup` | 彩妆包装 | Makeup Packaging | 2 |
| `homecare` | 家清包装 | Home Care Packaging | 3 |

**维度二：材质（Material）**

| 分类 ID | 中文名 | 英文名 | Demo 产品数 |
|---------|--------|--------|------------|
| `glass` | 玻璃 | Glass | 3 |
| `acrylic` | 亚克力 | Acrylic | 3 |
| `plastic` | 塑料（PP/PET/HDPE/铝） | Plastic | 4 |

**维度三：包装类型（Type）**

| 分类 ID | 中文名 | 英文名 | Demo 产品数 |

| `bottles` | 瓶类 | Bottles | 5 |

> 产品可跨应用分类归属（如乳液瓶同时归属 `skincare` 和 `homecare`），通过 `categories.application` 数组实现。

## 二、核心产品数据结构

### 2.1 产品核心属性

每个产品由以下维度描述（对应 PXM PIM 模块的属性配置）：

**基础信息**
- 产品名称（中/英文）
- 产品系列
- 所属分类（应用 + 材质 + 类型 三个维度）
- 产品 slug（URL 标识）

**技术规格**
- 容量（ml）：如 15ml / 30ml / 50ml / 100ml
- 材质：主材质 + 配件材质
- 外径/高度（mm）
- 净重（g）
- 开口尺寸（mm）

**定制选项**
- 可选颜色（标准色 + 潘通定制）
- 表面处理：光面 / 哑面 / 磨砂 / 电镀
- 印刷工艺：丝印 / 烫金 / 压纹 / UV 印刷
- 是否支持 Logo 定制
- 是否支持换色

**商务信息**
- MOQ（最小起订量）：500 / 1000 / 3000 / 5000
- 阶梯价格（3-4档）
- 交期（天）：标准款 / 定制款
- 样品费用

**媒体资产**（对应 PXM DAM 模块）
- 主图（1张）
- 产品图库（4-8张）
- 3D 模型链接（部分产品）
- 技术图纸（可选）

## 三、B2B 业务流程

### 3.1 客户旅程

```
发现阶段          评估阶段          决策阶段          执行阶段
─────────────    ─────────────    ─────────────    ─────────────
浏览分类导航  →  产品筛选比较  →  询价/样品申请  →  下单/生产跟踪
     ↓                ↓                ↓                ↓
查看热门产品       产品详情查看      3D效果预览        支付/物流
     ↓                ↓                ↓                ↓
关注新品/案例      规格参数确认      方案定制          收货验收
```

### 3.2 询价流程

```
客户填写询价表单
    ↓
系统自动确认邮件（含询价编号）
    ↓
销售 24h 内响应（Demo 中展示流程）
    ↓
发送初步报价单（PDF）
    ↓
样品确认（可选）
    ↓
正式下单
```

### 3.3 定制服务流程

```
选择基础产品
    ↓
进入定制配置界面（3D 预览）
    ├── 选择颜色（色卡 / 潘通号输入）
    ├── 选择表面处理（光面/哑面/电镀）
    ├── 上传 Logo / 设计稿
    └── 选择印刷工艺
    ↓
保存定制方案（心愿单）
    ↓
一键提交询价（含定制需求）
```

## 四、页面内容规划

### 4.1 首页内容结构

| 模块 | 内容 | PXM 关联 |
|-----|------|---------|
| Hero Banner | 品牌定位语 + 视觉大图 + CTA | DAM 图片管理 |
| 产品分类入口 | 护肤/彩妆/家清 3 大类 | PIM 分类管理 |
| 热门产品 | 8 个精选产品卡片 | PIM 产品推荐标签 |
| 核心优势 | 4 项 USP + 图标 | 静态内容 |
| 数字展示 | 500+ 产品 / 200+ 客户 / 15 年经验 | 静态数据 |
| 客户案例 | 合作品牌 Logo 墙 | CMS 案例管理 |
| 联系 CTA | 询价入口 | 表单提交 |

### 4.2 产品列表页筛选项

```typescript
// 筛选维度（对应 PIM 属性）
interface ProductFilters {
  application: 'skincare' | 'makeup' | 'homecare'  // 应用场景
  material: 'glass' | 'acrylic' | 'pp' | 'pet' | 'hdpe' | 'aluminum'  // 材质
  type: 'bottle' | 'jar' | 'tube' | 'pump' | 'ampoule'  // 包装类型
  capacity: '0-30' | '30-100' | '100-300' | '300+'  // 容量范围（ml）
  isCustomizable: boolean  // 是否可定制
  isNew: boolean  // 是否新品
}
```

### 4.3 产品详情页内容模块

```
产品详情页
├── 面包屑导航
├── 产品媒体区
│   ├── 主图 + 缩略图切换
│   └── 3D 预览按钮（启动 Studio）
├── 产品信息区
│   ├── 产品名称 + 型号
│   ├── 一句话描述
│   ├── 材质标签 + 定制标签
│   ├── MOQ 信息
│   └── CTA：询价 / 申请样品 / 加入心愿单
├── 规格参数表
│   └── 全部技术参数（结构化展示）
├── 定制配置区（可选）
│   ├── 颜色选择
│   └── 表面处理选择
├── 包装信息
│   └── 阶梯价格表（按数量区间）
└── 相关产品
    └── 4-6 个同类/配套产品
```

## 五、多语言规划

Demo 支持中文 / 英文双语，体现 PXM 的多语言管理能力：

| 内容类型 | 多语言字段 |
|---------|---------|
| 产品名称 | `name.zh` / `name.en` |
| 产品描述 | `description.zh` / `description.en` |
| 规格标签 | `specs[].label.zh` / `specs[].label.en` |
| 分类名称 | `category.name.zh` / `category.name.en` |
| UI 文案 | `locales/zh.json` / `locales/en.json` |

## 六、Demo 演示脚本

### 演示路径 A：产品管理能力
1. 进入产品列表页 → 展示多维筛选（PIM 属性管理）
2. 切换语言 → 展示多语言发布
3. 进入产品详情 → 展示结构化参数（PIM 数据质量）
4. 查看图片库 → 展示 DAM 数字资产管理

### 演示路径 B：定制配置能力
1. 进入产品详情 → 点击"3D 配置"
2. 选择材质/颜色 → 实时 3D 预览（Studio）
3. 上传 Logo → 效果预览
4. 保存方案 → 转化为询价

### 演示路径 C：B2B 业务流程
1. 首页 → 品牌定位展示
2. 产品浏览 → 选型过程
3. 加入询价列表 → 多产品对比
4. 提交询价 → 流程结束
