# 美妆包材 Demo 架构设计

> **定位**：模拟美妆包材品牌方（LuxePack）的真实对外独立站，向客户展示 Realibox PXM 平台能够为其搭建此类数字化门户的能力  
> **关键原则**：独立站本身不出现 PXM 品牌字样，PXM 能力通过网站功能隐性体现（结构化数据、多语言、3D 预览、多维筛选等）  
> **原型参考**：Jarsking（客户 POC）、晟祺实业、正庄实业、金雨科技

---

## 一、项目定位

### 1.1 Demo 目标

本 Demo 模拟一家名为 **"LuxePack"** 的美妆包材制造商的对外独立站，面向全球美妆品牌方提供定制化包装解决方案。

> **重要**：这是一个以 LuxePack **客户视角**呈现的网站，访客是 LuxePack 的目标客户（美妆品牌采购方）。演示时，销售人员在网站之外另行讲解：这些产品数据、3D 预览、多语言能力，背后都是由 PXM 平台统一管理和驱动的。

**PXM 能力在独立站中的隐性体现**：

| 网站功能 | 对应 PXM 能力 | 演示说明 |
|---------|-------------|---------|
| 产品多维筛选（材质/应用/容量） | PIM 多属性管理 | "这些筛选维度背后，是 PIM 对每个 SKU 的结构化属性管理" |
| 产品详情参数表 | PIM 结构化数据 | "所有规格数据标准化入库，一次维护全平台同步" |
| 中英文一键切换 | PIM 多语言管理 | "多语言内容在 PIM 中统一维护，无需重复建站" |
| 产品图片库 | DAM 数字资产 | "图片、3D 模型、技术文档集中在 DAM 管理" |
| 3D 在线预览 | Studio 配置器 | "Realibox Studio 实时渲染，客户自助定制" |
| 阶梯价格展示 | PIM 价格规则 | "复杂定价逻辑在平台中配置，前端自动计算" |

### 1.2 目标用户

| 用户类型 | 需求场景 | 核心痛点 |
|---------|---------|---------|
| 新兴美妆品牌 | 寻找 OEM 包装供应商 | 不了解市场选项，难以比较规格 |
| 成熟品牌采购 | 批量定制、换季更新 | 沟通效率低，确认周期长 |
| 海外买家 | 在线浏览、快速询价 | 语言障碍、无法快速获取技术参数 |
| 品牌设计师 | 3D 效果预览 | 实物样品成本高、周期长 |

## 二、网站页面架构

### 2.1 页面结构总览

```
LuxePack 独立站
├── 首页 (/)
│   ├── Hero Banner - 品牌定位
│   ├── 产品分类入口 - 应用×3 + 材质×3 双入口
│   ├── 精选产品 - 6个 isFeatured 产品卡片
│   ├── 核心优势 - 4大价值主张（隐性体现 PXM 能力）
│   └── 联系 CTA
│
├── 产品总览 (/products)
│   ├── 三维筛选器（应用/材质/类型，可多选）
│   └── 10个 SKU 产品卡片网格
│
├── 按应用浏览 (/products/application/[id])
│   ├── 护肤包装 (/products/application/skincare)
│   ├── 彩妆包装 (/products/application/makeup)
│   └── 家清包装 (/products/application/homecare)
│
├── 按材质浏览 (/products/material/[id])
│   ├── 玻璃系列 (/products/material/glass)
│   ├── 亚克力系列 (/products/material/acrylic)
│   └── 塑料系列 (/products/material/plastic)
│
├── 产品详情 (/products/[slug])
│   ├── 产品主图 + 图库
│   ├── 规格参数表
│   ├── 定制选项（颜色/印刷工艺）
│   ├── MOQ & 阶梯价格
│   ├── 3D 配置入口（has3DModel=true 时显示）
│   └── 相关产品推荐
│
├── 关于我们 (/about)
│   ├── 品牌故事
│   ├── 生产能力
│   └── 认证资质
│
└── 联系询价 (/contact)
    ├── 询价表单
    └── 样品申请
```

> **取消页面**：`/customization`（定制服务独立页）、`/case-studies`（成功案例页），Demo 阶段不实现。

### 2.2 核心页面详细说明

#### 首页
- **Hero**：全屏视觉，突出"高端定制"品牌定位，双语切换
- **分类入口**：护肤/彩妆/家清 3 大类，图片+描述
- **热门产品**：6-8 个热销产品卡片
- **核心优势**：品质保障/快速交付/小批量 MOQ/全面定制，4 项 USP
- **定制流程**：四步流程（选择产品 → 在线配置 → 获取报价 → 生产交付），引导客户行动
- **联系 CTA**：直达询价入口

#### 产品列表页
- **多维筛选**：应用场景 + 材质 + 包装类型 + 容量范围（展示 PIM 属性管理能力）
- **产品卡片**：图片/名称/材质/MOQ/定制标签
- **切换视图**：网格视图 / 列表视图

#### 产品详情页
- **媒体展示**：主图 + 多角度图片 Gallery + 3D 模型入口
- **规格参数**：结构化展示所有技术参数（展示 PIM 数据结构化能力）
- **定制配置**：颜色选择、印刷工艺选择、材质升级
- **商务信息**：MOQ / 阶梯价格 / 交期
- **询价/样品申请** CTA

## 三、技术架构

### 3.1 技术栈

| 层次 | 技术选型 | 说明 |
|-----|---------|------|
| 框架 | Next.js 14（App Router） | SSR/SSG，SEO 友好 |
| 样式 | Tailwind CSS | 原子化 CSS |
| 组件 | shadcn/ui | 高质量 UI 组件 |
| 动画 | Framer Motion | 页面过渡与微交互 |
| 国际化 | react-i18next | 中英文双语 |
| 图标 | Lucide React | 统一图标库 |
| 数据 | 本地 JSON 静态数据 | 模拟 PXM 数据源 |
| 3D | iframe 嵌入 Realibox Studio | 演示 3D 配置能力 |

### 3.2 数据流架构

```
模拟数据层（JSON 文件）
    ↓ 模拟 PXM API 输出
Next.js 服务端渲染
    ↓ 页面数据注水
前端交互层（React 客户端组件）
    ↓ 用户操作
询价/定制意向收集
```

> **演示重点**：JSON 数据文件的结构设计，直接体现 PXM 的数据建模能力。
> 在 Demo 中，数据文件 = PXM 产品数据库的输出快照。

## 四、PXM 能力映射

Demo 中每个功能模块都对应 PXM 的具体能力，演示时可以直接关联说明：

| Demo 功能 | 对应 PXM 能力 | 演示价值 |
|----------|-------------|---------|
| 产品多维筛选 | PIM 多属性管理 | 复杂产品属性的统一管理 |

| 产品图片库 | DAM 数字资产 | 产品图片的集中管理 |
| 3D 在线预览 | Studio 配置器 | 实时 3D 产品配置 |
| 阶梯价格展示 | PIM 价格规则 | 复杂定价逻辑管理 |
| 相关产品推荐 | PIM 产品关联 | 产品关系图谱管理 |
| 询价数据收集 | 应用管理 | 前端应用与平台数据打通 |
